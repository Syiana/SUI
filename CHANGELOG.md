# SUI

## 2.0.0 (unreleased)

Complete rebuild of SUI.

- One addon for Retail, Mists of Pandaria Classic, Burning Crusade Classic and Classic Era.
- New modular core: every feature can be switched on and off and applies live, most without a reload.
- Settings from SUI 1.x are migrated automatically; 1.x profile strings can still be imported.
- Profiles: create, copy, switch and delete, plus import/export.
- Options menu keeps the SUI look, now grouped with search, dependent options and per-tab reset.
- Theme changes repaint the interface live.
- Large performance work: no permanent per-frame updates, event-driven range colors, nameplate and raid frame updates only when values change.
- New features include proc glow styles, boss castbars, raid frame buff/debuff layouts, minimap button bar, Mythic+ and PvP ratings in tooltips, player links, chat whisper sound, quest/gossip/role check automation and more.
- Nameplate options are reachable again; modules that were never loaded in 1.x (cast timer, totem icons, resurrection) work.
